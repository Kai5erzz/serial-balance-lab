# RMUC2026 MuJoCo 静态场地

使用 RoboMaster 官方 **RMUC2026_V2.0.0.stp（Finals 总决赛）** 转换，核心场地尺寸 28 × 15 m。包括中央高地、两侧公路、坡道、台阶及基地、补给和能量机关等设施的 CAD 外观。

这是基于 CAD 的静态地形。活动设施固定在 CAD 中的姿态；裁判系统、矿石交互、机关驱动和比赛逻辑没有实现。开放曲面的设施外壳，以及面数超过 5 万且尺寸小于 2.5 m 的高精度机关零件，使用保守凸包，不能用它验证机关内部的通行或操作。比赛地贴、标线和文字没有完整复刻。

## 直接使用

当前工作区：`/home/kaiser/robomaster/rl-lab/terrain_rmuc2026`。

### 整车操控窗口

```bash
cd /home/kaiser/robomaster/rl-lab
/home/kaiser/.local/bin/mujoco-gpu --validation \
  /home/kaiser/miniconda3/envs/rl-lab/bin/python run_operator.py \
  --variant rmuc2026 --controller-profile jump46 \
  --interface-mapping coherent_candidate --yaw-damping 0 \
  --width 960 --fps 30
```

窗口初始暂停，默认显示纯文本键位说明，按 **P** 开始。**H** 隐藏全部说明和状态文字，仅保留画面与中央靶心；再按 H 恢复。**F11** 切换全屏和窗口，Esc 暂停并退出全屏，也可在启动命令后添加 `--fullscreen`。窗口可调整大小，场景按比例显示；全屏保持原 GPU 渲染分辨率。

W/S 前后，A/D 转云台，右键按住拖动云台、松开释放，Shift 满速、Ctrl 慢速，Space 跳跃，X 中腿、Z 低腿，C/B 磕台阶，M 全场俯视、Tab 第一/第三人称，R 回到出生点并暂停。第三人称按住左键拖动旋转视角、滚轮缩放；镜头跟随车辆位置，方向固定在世界坐标，不随云台转动，切换视角后保留所选方向。第一人称仍跟随云台。云台灵敏度用 **[ / ]** 减小或增大，默认值保持原样。

这是当前机器人和真实 C 控制回调的操作入口，使用仿真独立的 `jump46` 配置（单髋峰值 40 N·m、总请求上限 160 N·m）。仅修改仿真，`code_914` 原始控制器不变。机器人沿用 2025 场景已校正的 CAD 车身接触和车底支撑范围。当前 C/B 磕台阶接近腿长目标为 **32 cm**，退出连续缓降；部分斜角改善，但 −3° 对照退步，慢速及 X≈−6 处实际 20 cm 路沿仍未通过，见 [加高实测与限制](../docs/NATIVE_BUMP_TALLER_20261015.md)。

整车场景默认添加 **28 × 15 m 内边界**的蓝色半透明围挡，具有真实碰撞；围挡顶边为亮蓝色，按 M 可查看全场边界。它是仿真防出界设施，未改动原始 CAD 地形。墙底延伸至 Z=-0.4 m，墙顶 Z=2.4 m，以覆盖 CAD 倾斜地面的边缘。

此入口使用此前用户授权的独立验证锁，可与训练的 `heavy_run` 并行；启动器每 0.1 秒监测可用内存，低于 **2500 MiB** 时停止自身。2025 和 2026 操作窗口共用这把验证锁，应先关闭一个再开另一个。不要在启动器外再嵌套 `heavy_run.sh`。

首次加载会编译物理模型和显示模型，之后直接读取缓存。新增缓存跟随地图资源，位于 D盘2 的 `rl-lab-terrain/rmuc2026/operator-cache/`。物理模型保留地图包全部接触体；显示模型采用独立的空间分块，只隐藏镜头外的显示块，不改变物理反馈。显示直接使用包内已简化的视觉网格，没有再次减少三角面。

操控出生点为开阔地面 `(-8.75, -2.25)` m，地面高度约 `0.09989491` m，原始高度采样见 `operator_spawn.json`。地图包被动装配示例的 `(-11.25, -6.25)` 位于设施墙边，不作为操控默认点。场地机关仍是静态设施，设施内部的代理碰撞和陡台阶不能据此视为可通行。

与 RL-lab 当前机器人组合的例子（读取源 XML，输出一份新场景）：

```bash

  --robot model/whole_body_lqr_fast.xml \
  --output /tmp/rmuc2026_robot.xml \
  --profile collision --spawn -11.25 -6.25 0.59815229

```

示例使用 `checks/spawns.json` 的第一个出生点，机体初始 Z 为该点地面高度加 0.6 m。其他出生点也按这个规则设置。装配脚本保留机器人自身的关节和执行器定义；查看器没有接入机器人控制回调，机器人会按被动动力学运动。控制器试验应由 RL-lab 的控制运行器加载生成的场景。

`compose.py` 面向当前 RL-lab 的直接资源路径 MJCF。外部模型如果有多层 include、默认类命名冲突或特殊接触过滤，需要单独检查。输出的组合 XML 使用机器人资源绝对路径，不能随地图 ZIP 搬到另一台机器。

可搬运 ZIP 中的 `pack` 仅使用相对资源路径。解压后把整个目录一起移动，使用 MuJoCo 3.12 打开 `pack/scene.xml` 即可；无需原始 STEP 或 CAD 转换依赖。包装脚本中的 Python、jointpd 路径是本机配置，在另一台机器运行脚本时须相应调整。

## 坐标和接触

单位为米；X 沿场地长边，Y 沿短边，Z 向上。XY 原点取 CAD 总装水平外包围盒的中心；Z 原点取 CAD 大面积向上地面的主高度。CAD 本身包含地面倾斜，所以不能把任意 XY 的地面高度都当成零。精确转换矩阵与平移见 `pack/manifest.json`。

地形 `contype=4`、`conaffinity=3`，与 RL-lab 现有车辆接触位相容。视觉网格 `contype=0`、`conaffinity=0`，不会产生第二层碰撞。接触组为 3，视觉组为 1。

摩擦系数 `1.2 0.02 0.001` 沿用 RL-lab 假设值，**没有实测官方地胶摩擦**。`solref=.008 1`、`solimp=.92 .99 .002` 是当前仿真设置。

围挡内边界为 28 × 15 m，厚度 50 mm 是建模假设，门洞未建模。地图包原始 `scene.xml` 保持不带围挡，`scene_bounded.xml` 包含包内可选围挡。整车操控入口及 `compose.py` 装配默认使用可见、可碰撞围挡；单独装配可传 `--no-perimeter` 关闭。操控入口的围挡向地下延伸，顶边和墙面同时出现在显示模型中。

用户最新确认的台阶在起伏路段与隧道之间，**X≈-6.0 m、Y≈-5.42 m**。这一处实际高差约 **20 cm**，没有另高 15 cm 的挡边；55 个采样点的原始 CAD 台面与接触模型高度一致。当前 C/B 在这里仍不能稳定上台：候选配置曾正对成功，但偏移和斜向检查失败，因此未部署候选参数。详见 `../docs/RMUC2026_X6_STEP_CAMERA_AUDIT_20261015.md`。

此前核对的 X=-9.25 m、Y≈-3.55 m 浅色路沿是另一处，约 35 cm 的结论不适用于用户本次所指位置；其独立几何记录保留在 `../docs/RMUC2026_BOUNDARY_STEP_AUDIT_20261015.md`。

## 几何处理和验证边界

视觉直接来自官方 CAD，按材质分组，清理重复和退化面后简化。部分地面和抬高地形用深灰、灰色区分，其余保留 CAD 配色；原始 CAD 配色仍保存在本机转换中间文件中。显示简化不影响用于生成碰撞和核对高度的原始 CAD 三角面。

碰撞按各个 CAD 实体分别构建。凸实体使用凸包；平板保留三角剖分形成的孔洞；适合的凹实体使用 TetGen 约束四面体剖分后合并凸块；其他实体使用有内存和时间上限的 CoACD。两块公路弯坡按 120 mm 的 XY 小区域裁切原始三角面，再分别取局部凸包，保留源实体的底面边界；没有把这些区域向下延伸至地板。这个局部凸化仍是一种近似，误差由独立 CAD 高度采样核对。

没有对整张地图套一个凸包，也没有使用单值高度场。细节密集的框架零件采用 CAD 边界向内加厚 1 mm 的薄壳碰撞，内部未填成实体。小五金件避免产生数千个四面体接触块，改用有上限的 CoACD；极小五金件省略碰撞。详细策略、剖分输入被拒绝的原因和各部件参数记录在 manifest。

开放曲面设施外壳不具备可靠闭合体积，因此采用保守凸包；高精度机关零件也采用保守凸包来限制内存和接触复杂度，ID 单列在 manifest 中。这些区域在高度对比中**单独列为设施代理样本**，不计入地形误差通过指标；详细记录仍全部保留。高度采样与少量落球检查不能证明所有孔隙、横向净空和机器人动作均已验证。
