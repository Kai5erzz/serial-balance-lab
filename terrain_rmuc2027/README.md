# RMUC2027 仿真地图

由 RoboMaster 官方 **RMUC2027_V1.0.0.stp** 转换的 MuJoCo 静态赛场，对应 **RMUC 2027 比赛规则 V1.0.0**。场地核心尺寸为 **28 × 15 m**，保留公路、起伏路段、隧道、高地、制高点、基地等设施的 CAD 外观。

地图已接入轮腿机器人操控窗口，可进行驾驶、平衡、跳跃与地形接触调试。地图中的活动机关保持静态，尚未实现比赛裁判逻辑和能量机关交互。

## 启动仿真

按[项目首页](../README.md#安装与启动)安装依赖后，在仓库根目录运行：

```bash
python run_operator.py --variant rmuc2027 --fullscreen --fps 30
```

默认暂停、显示中文键位说明。按 **P** 起身并运行，**R** 重置，**H** 隐藏或显示文字，**F11** 切换全屏。完整键位见[操控方式](../README.md#操控方式)。

第三人称方向固定在世界坐标，左键拖动观察视角；右键拖动云台，松开释放鼠标。默认出生点为地板位置 `(-6.25, -4.75)`，该点采样地面高度为 `0.012843875 m`。

## 场景与碰撞

单位为米，X 为长边、Y 为短边、Z 向上。XY 原点位于 CAD 总装水平包围盒中心，Z 原点取大面积地面的主高度。官方地面带有倾斜，各处地面高度不完全相同。

整车操控场景默认添加内边界 **28 × 15 m**、顶部高 **2.4 m** 的外围围挡；围挡是仿真边界，未复刻门洞。独立 `scene.xml` 保留不带额外围挡的 CAD 场景。

视觉资源保留 CAD 配色、标线和文字几何。操控窗口使用预生成的显示简化模型，将约 205.2 万三角面降至 167.3 万面，保留连通部件和开放边界；显示简化不改变物理碰撞。完整视觉仍保存在运行地图包内。

地形碰撞保留道路、坡面、隧道和悬空空间，未使用覆盖全场的单值高度场或整图凸包。部分复杂设施外壳采用保守简化，其内部空间不保证可通行。地面摩擦参数为 `1.2 0.02 0.001`，属于仿真设置，尚未按官方地胶实测标定。

## 验证与已知限制

以下为 MuJoCo 3.12.0 下的检查记录：

| 检查 | 结果 |
| --- | --- |
| 地形高度 | 1,666 个地形采样点，最大高度误差 **9.337 mm** |
| 地形悬空间隙 | 74 处通过，顶板与地面边界最大误差 **4.311 mm** |
| 接触探针 | 地板、公路和中央高地各一处，局部稳定高度误差不超过 **0.321 mm** |
| 整车装配 | 完整物理场景包含 49,965 个 geom，含机器人与围挡 |
| 短程驾驶 | 起身、慢速前进与松开操作共 8,000 个真实 C 控制 tick，无起身或跳跃故障 |
| 操控界面 | 第一、第三人称、全场俯视、全屏、默认说明、隐藏文字和重置检查通过 |

**设施内部仍有明确误差：** 14 个设施高度样本和 22 个设施间隙样本单列记录，最大高度偏差 824.8 mm、间隙边界偏差 383.8 mm。这些区域不能用于验证设备内部穿行。

采样检查和短程驾驶不能证明全场任意路线可通行。高速跳跃落地、台阶和复杂设施通行仍需分别验证；地图加载成功不代表全部动作已通过验收。当前仿真专用跳跃参数及其他控制限制见[项目首页](../README.md#仿真范围与限制)。
