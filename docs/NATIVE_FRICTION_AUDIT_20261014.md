# 共用实车 C 控制器的摩擦排查

2026 年 10 月 14 日，针对当前自起身失败完成了 26 组摩擦和关节阻力对照，其中 25 组数值有效，没有一组通过末段物理站立验收。提高轮轴阻尼或底部摩擦会改变恢复过程，有些设置能让固件给出站立确认，但仍有倾斜、轮子离地和非轮部件支撑。现有结果不能把失败归结为单一摩擦参数，也不足以采用新的默认参数。

用户确认实车底部摩擦较大，导轮几乎不能自行滚动。因此保留底部固定接触面的近似。该描述支持高阻力接触，但不能确定具体摩擦系数；本次的 2.0 等数值均为诊断对照。

## 实际生效的接触参数

当前模型没有显式 contact pair，碰撞几何的 priority 均为 0。相同优先级时，MuJoCo 对两个几何体的摩擦参数逐项取较大值。因此地面 1.2、轮子 1.0、快速模型导轮 0.9、完整模型滑块 0.8 的组合，实际生成的地面接触滑动摩擦系数都是 **1.2**。只把导轮从 0.9 改到 0.3，实际接触摩擦仍为 1.2。[MuJoCo 接触参数规则](https://mujoco.readthedocs.io/en/stable/modeling.html#contact-parameters)

实际接触的 condim 都为 3，只启用法向与两个切向滑动约束。摩擦三元组里的扭转和滚动参数没有启用；它们分别需要 condim 4 和 6。轮轴关节阻尼仍然生效，不能与接触滚动摩擦混为一谈。[MuJoCo condim 定义](https://mujoco.readthedocs.io/en/stable/XMLreference.html#body-geom-condim)

底部 guide_wheel_contact 固定在 base_link 上，没有独立滚动关节。完整碰撞模型使用 recovery_skid，并保留其他实体碰撞几何。高摩擦对照分别测试仅提高该底部接触面，以及提高所有非轮接触面的情况。

为单独改变某组的实际接触摩擦，诊断工具将地面滑动摩擦设为 0，并在机器人各接触面上指定目标系数。未变更组的实际系数保留 1.2，法向接触参数保持原值。报告中的实际 contact.friction 已核对这一点；这些改动只存在于各次试验的内存模型。

## 关节阻力与气弹簧

默认 identified_2026-09-21 profile 的轮轴阻尼为 0.0082 N·m·s/rad，轮轴库仑阻力为 0。原 XML 轮轴阻尼为 0.08 N·m·s/rad。本次测试包括阻尼为零、四分之一、四倍、原 XML 值，以及增加 0.09 N·m 库仑阻力。

四髋与被动关节的历史辨识阻力保持不对称，单位分别为 N·m·s/rad 和 N·m：

| 关节组 | 粘性阻尼 | 库仑阻力 |
| --- | ---: | ---: |
| l_j1 | 0.739016 | 0.515040 |
| l_j2 | 0.092712 | 0.424873 |
| r_j1 | 0.038895 | 0.546239 |
| r_j2 | 0.082404 | 0.445817 |
| 左侧被动关节，各关节 | 0.025434 | 0.153053 |
| 右侧被动关节，各关节 | 0.302338 | 0.563067 |

降低或清除这些阻力没有使模型通过站立。接触系数属于名义配置，历史辨识结果也不能替代当前固件整车自起身的验证；本次没有重拟合或覆盖原 profile。

气弹簧不存在物理重复施力：两个 tendon 的 stiffness、damping、frictionloss 均为 0，没有对应的气弹簧执行器；接口在每拍清空外力后，分别施加左右各 300 N 的被动力。原始 C 中的气弹簧补偿属于控制命令计算，与物理被动力承担不同职责。

## 对照结果

各组从 jointpd 精确编码器初始姿态启动，先松控 50 ms，再使用原始 DR16 右拨杆 3 请求自起身。所有组执行同一份当前实车 C 控制链，控制节拍 1 ms，每组 5 s，末段统计窗口为 4 至 5 s。共 20 组快速模型与 6 组完整碰撞模型。

物理站立验收要求末段 pitch、roll 绝对值均小于 5°，双轮同时接触超过 95% 的时间，非轮部件接触峰值小于 1 N，站立确认超过 95%，左右 phi0 偏离 90° 均小于 20°。接触判定以每轮法向力大于 1 N 为准。该验收用于当前仿真诊断，没有被写入实车控制器。

| 模型与对照 | pitch 峰值 ° | roll 峰值 ° | 双轮接触时间 % | 非轮接触峰值 N | 固件站立确认时间 % |
| --- | ---: | ---: | ---: | ---: | ---: |
| 快速，默认 | 15.35 | 0.92 | 0.4 | 1023 | 0 |
| 快速，仅底部摩擦 2.0 | 15.09 | 1.41 | 0.8 | 1052 | 0 |
| 快速，所有非轮摩擦 2.0 | 16.09 | 0.81 | 28.5 | 257 | 100 |
| 快速，轮轴阻尼四倍 0.0328 | 14.82 | 2.43 | 56.4 | 377 | 100 |
| 快速，轮轴阻尼原 XML 值 0.08 | 11.37 | 0.52 | 66.0 | 628 | 0.1 |
| 完整，默认 | 16.51 | 75.70 | 2.1 | 752 | 0 |
| 完整，仅底部摩擦 2.0 | 179.73 | 74.56 | 0 | 1641 | 16.7 |
| 完整，轮轴阻尼四倍 0.0328 | 140.79 | 10.06 | 10.8 | 941 | 23.0 |
| 完整，轮子摩擦 1.0 | 10.74 | 1.38 | 10.3 | 766 | 100 |

以上各组均未通过物理验收。完整模型中提高底部摩擦、提高轮轴阻尼的两组在给出短暂站立确认后翻倒，并出现恢复故障 11。快速模型把轮子摩擦提高到 2.0 时，末段 pitch 虽小于 1°，但双轮接触为 0、腿姿态不符，仍在恢复流程中，不能视作站稳。

唯一数值无效组是所有接触摩擦为零：第 11 拍出现 BADQACC，MuJoCo 自动重置。该组已明确标为失败，不能用于比较站立指标。

固件的站立确认与物理站稳需要分开判断。当前 recovery 的 LQR_HANDOFF 转入 DONE 主要检查接管增益和腿长变化率，并不直接要求机体姿态或双轮接触通过上述物理验收。因此状态位可以先完成，而模型仍靠底部支撑；本次保持实车原判据。

快速模型默认组在 1.181 s 进入 LQR_HANDOFF。当时双轮仍接地、切向滑动较小；随后轮电流达到约 ±8191，约 1.5 s 时两轮已离地并高速空转。该时间关系说明交接后的支撑轨迹和轮轴动力学值得继续核对，不能单凭末段空转认定最初失败由轮胎打滑引起。提高轮轴阻力的作用也随碰撞模型改变，不能从快速模型单独确定实车阻尼。

## 数值异常检测与记录

MuJoCo 的自动重置可能让 qpos、qvel 重新变为有限值。物理接口现已同时检查 BADQPOS、BADQVEL、BADQACC 警告与物理时钟连续性，发现异常立即停止，不再将重置后的轨迹当作有效控制历史。修改后 14 项共用控制接口测试通过，零摩擦极端组也正确触发失败。

完整汇总位于 `out/native/friction_audit/summary.json`，保留 26 组结果及原始报告路径和摘要。原始报告、100 Hz 轨迹 CSV 和接触明细分别位于该目录及 `intermediate/`、`wheel_followup/`、`high_contact/`、`full/`。每拍计算接触力与末段指标，每 10 拍保存逐接触的系数、维度、法向力、切向力和滑动速度。接触力来自该次 mj_step 的求解缓存，滑动速度按步后状态计算，两者存在最多一个物理步的采样相位差。

报告保留固件与主机控制接口身份。旧批次未记录的执行时工具摘要不会用当前摘要补填；汇总中的 current_analysis_probe_sha256 只描述当前分析工具。旧报告的 wheel_current_saturation_fraction 在汇总中更名为 wheel_current_ge_8190_fraction，数值未改：它表示电流命令绝对值达到固定阈值 8190 的时间比例，不代表每种底盘模式的实际限幅。

## 复现与后续核对

在 rl-lab 环境执行：

```bash
# 快速模型全部 20 组；使用新目录以保留本次原始报告。
python tools/probes/native_friction_audit.py \
  --output out/native/friction_audit_rerun/fast

# 完整碰撞模型的 6 组。
python tools/probes/native_friction_audit.py --variant full \
  --cases baseline wheel_mu_1.0 nonwheel_mu_1.0 no_leg_coulomb \
          wheel_viscous_fourfold guide_mu_2.0 \
  --output out/native/friction_audit_rerun/full
```

下一步优先核对轮电机速度与力矩关系，以及 LQR 接管时的腿部支撑几何、接触位置和气弹簧作用方向。仅靠这 26 组单项阻力对照，无法排除摩擦与其他物理差异的共同作用；站立和自起身通过之前，第一阶段的实车物理 1:1 仍未完成。
